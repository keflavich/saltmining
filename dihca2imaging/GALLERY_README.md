# DIHCA Spectral Analysis Gallery

## Overview

The DIHCA Spectral Analysis Gallery provides a responsive web interface for viewing diagnostic images generated by the spectral analysis pipeline. The gallery automatically organizes images by source and spectral window, with full-screen viewing capabilities.

## Features

- **Responsive Design**: Adapts to different screen sizes and devices
- **Source Organization**: Groups diagnostic images by source field
- **Spectral Window Display**: Shows all 4 spectral windows for each source
- **Full-Screen Gallery**: Click any image to open modal viewer
- **Keyboard Navigation**: Use arrow keys to navigate between images
- **Thumbnail Navigation**: Quick access to any image via thumbnails
- **Auto-Generation**: Automatically finds and includes all diagnostic images

## Gallery Structure

The gallery displays:
- **Source Sections**: Each source gets its own section with a clear title
- **SPW Grid**: 4 spectral windows arranged in a responsive grid
- **Modal Viewer**: Full-screen viewing with navigation controls
- **Statistics**: Shows total number of sources and images

## Files

### `gallery.html`
The main gallery webpage that displays all diagnostic images in an organized, interactive format.

### `generate_gallery.py`
Python script that automatically generates the gallery HTML by:
- Scanning the results directory for diagnostic PNG files
- Organizing images by source field
- Creating responsive HTML with embedded JavaScript
- Generating navigation and modal functionality

### `update_gallery.py`
Convenience script that updates the gallery after new analyses are run.

## Usage

### Manual Gallery Generation
```bash
# Generate gallery for all images in results directory
python generate_gallery.py spectral_analysis_results

# Generate gallery for a different directory
python generate_gallery.py /path/to/results
```

### Automatic Gallery Update
```bash
# Update gallery with any new images
python update_gallery.py
```

### Integration with Analysis Pipeline
The gallery can be automatically updated after running spectral analysis:

```bash
# Run analysis and update gallery
python run_batch_analysis.py 10
python update_gallery.py
```

## Technical Details

### Auto-Discovery
The gallery generator automatically:
1. Scans subdirectories for `*diagnostics.png` files
2. Extracts source names from directory structure
3. Identifies spectral window numbers from filenames
4. Organizes images hierarchically

### Performance
- Lazy loading of modal content
- Optimized image sizing
- Minimal JavaScript dependencies
- Fast rendering for large numbers of images

### Browser Compatibility
- Modern browsers with ES6 support
- Chrome, Firefox, Safari, Edge
- Mobile browsers supported
